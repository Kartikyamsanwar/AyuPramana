# AyuPramana — IP-SAKTI Sahayak (SIH26045)

A multilingual (English, हिंदी, मराठी), source-cited assistant for intellectual-property and regulatory questions
about Ayurvedic products. Every answer cites the exact provision and document version it comes from, and the
assistant abstains when the sources don't answer the question.

Code: https://github.com/Kartikyamsanwar/AyuPramana

*This is information, not legal advice.*
